# 缠论结构分析 · 完整使用说明

本文件是 `SKILL.md` 的详细展开。SKILL.md 只保留快速上手、使用实例与常见错误；**本文件包含执行细节、参数映射与算法说明**。执行分析时如对细节有疑问，以本文件为准。

---

## 1. 执行流程（完整版，每次分析固定按此 4 步走）

### 第 1 步：拉取 K 线数据（对话中调用通达信 MCP）

1. **确认代码**：若用户给出的是中文名称（如"茅台"）或存疑代码，先调用 `tdx_lookup_stock` 获取精确纯数字代码。
2. **确定 setcode（市场代码）**：
   - `1` = 沪市（6/68 开头）
   - `0` = 深市（00/30 开头）
   - `2` = 北交所（43/83/87）
   - 其他市场按实际市场传对应值。
3. **确定 period**（见下方映射表）。
4. **调用 `tdx_kline`**，参数：
   - `period`：按操作级别映射
   - `wantNum`：**300 根**（不足则取全部）
   - `tqFlag`：`"1"`（前复权，保证走势连续）
   - `setcode`、`code` 匹配正确。
5. **获取实时行情**（可选，用于报告头部）：调用 `tdx_quotes` 取换手率、当前涨跌幅。

### 第 2 步：把数据保存为约定格式

把第 1 步拿到的 K 线，保存为 JSON 到固定目录：
**`assets/data/{code}_{period}.json`**

文件格式（务必严格遵循）：

```json
{
  "code": "300058",
  "period": "30min",
  "name": "蓝色光标",
  "meta": {"change_pct": -0.98, "turnover": 14.12},
  "bars": [
    {"t": "20260624 48600", "o": 14.49, "h": 14.65, "l": 14.47, "c": 14.69},
    {"t": "20260624 50400", "o": 14.65, "h": 14.62, "l": 14.61, "c": 14.78}
  ]
}
```

- `bars` 按时间升序，`t` = "日期 时间(秒)"，四价取自通达信返回的 Open/High/Low/Close。
- `meta` 可选：`change_pct`（当日涨跌幅%）、`turnover`（换手率%）。没有则省略。

### 第 3 步：运行固定脚本（核心，勿改动）

```bash
python "assets/analyze.py" <code> <period> [name]
# 例：python "assets/analyze.py" 300058 30min 蓝色光标
```

脚本会自动：
1. 读取 `assets/data/{code}_{period}.json`；
2. 调用固定算法引擎 `assets/chanlon_engine.py` 计算**笔 → 中枢 → 买卖点 → 当前状态**；
3. 生成 `assets/output/{code}_{period}/chan-{code}-{period}.html`（完整报告）与 `assets/charts.js`（图表数据）；
4. 在控制台打印结构摘要（笔、中枢、现价）。

> 脚本 stdout 会打印完整笔序列与中枢，**务必据此核对与图表标注一致**。

### 第 4 步：检查并交付报告

- 打开生成的 HTML，确认图表正常渲染（K线、笔、中枢区间、ZG/ZD 标注）。
- 若报告叙述性文案需补充细节（如结合量能、大盘的具体点评），可在 HTML 内微调，但**不得改动笔/中枢/ZG/ZD 等结构数据**（那是固定算法结果）。
- 用 `present_files` 打开生成的 HTML 报告交付用户预览，并给出结构结论摘要。

## 3. 固定算法（已固化在 chanlon_engine.py，勿改）

`assets/chanlon_engine.py` 实现了全部沉淀逻辑，是唯一权威算法：

1. **K线包含合并**：按走势方向合并（高点取高/低点取高，或高点取低/低点取低）。
2. **分型识别·合并·确认**：顶/底分型，相邻同型取更极端，仅保留被反向K线确认的分型。
3. **严格成笔**：顶底交替，`MIN_GAP = 3`（分型间至少间隔 3 根合并K线）。
4. **内部极值矫正**：向上笔终点取区间内最高顶分型、向下笔取最低底分型，并级联更新后续笔起点；**过近极值忽略**（距起点 < MIN_GAP 的极值不作为矫正终点）。
5. **跨界延伸**：若下一笔起点在同一方向比本笔终点更极端，本笔终点延伸到下一笔起点。
6. **中枢构建**：连续三笔重叠，区间 = 三笔最高点中的最低值（ZG）与最低点中的最高值（ZD）；延伸并入落入区间的后续笔。
7. **连接段排除**：中枢结束后若最后一笔终点已离开区间，紧随其后的反向笔为连接段（三买/三卖确认笔），新中枢从其后的同向笔起始。
8. **买卖点检测**：三买（突破中枢上沿后回踩不破）、三卖（跌破下沿后反抽不破）为严格定义；一买/二买为区间极值的结构近似。**一买/二买排除进行中的最后一笔**——最近一笔端点未经后续走势确认，若把"下跌未走完的瞬低点"标成 1 买会误导（可能继续创新低）。
   - **一买/二买降级（broken）**：一买取"已完成笔最低点"后，若全区间（含未确认末笔）已出现更低价格（如末笔创新低），则该潜在一买已被破坏，仅作历史结构痕迹保留，图上标注为**"1买(失效)"（灰弱 0.75 透明，非有效买点）**；同锁定的二买一并降级失效。避免与末笔创新低的底背驰并存而造成"图上同时标 1买5.2 与 底背驰5.17"的自相矛盾。
   - **中枢上沿遇阻（减仓）**：对每个中枢，取其内/后第一根"向上笔终点触及上沿 ZG 却未有效脱离（终点 ∈ [ZG, ZG+0.1×(ZG-ZD)]）且紧邻下一笔为向下回落"的笔，标注**"减仓"**——中枢上沿压力/减仓点。该类笔未创新高、未确认离开中枢（否则属三买/离开段），故不标结构卖点，只作中性减仓参考。
9. **背驰判定（中枢感知 + 里程碑比较 + 终端极值过滤）**：
   - 里程碑：同向笔中逐次创新高(up)/新低(down)的笔，作为可比段；只比较每个方向的**终端里程碑**（全局极值）及其前一个里程碑。
   - **中枢感知分级**：
     - **走势级别·趋势背驰**：笔"确认离开"中枢（突破上沿/下沿后，紧邻反向笔回踩/反抽不破，=三买/三卖确认）后，与该中枢的进入段比较力度；力度衰竭 → 标"一买/一卖确认"。
     - **笔级别·盘整背驰**：中枢内部创新高/新低的笔（未确认离开），只与**紧邻同向笔**比较力度；力度衰竭 → 标"笔级别盘整背驰转折"，**不标一买/一卖**。
   - 该分级避免两类误判：① 把"被后创新高超越的中间高点/低点"误标（如4.18/4.50 被5.70超越后不再标注）；② 把"未确认离开中枢的末笔"直接与远离的中枢启动大段比较（如6.07 与4.16→5.70 大上升段比，级别不对等、产生背驰错觉）。
   - **级别说明**：当前算法检测到的绝大多数是**笔级别**盘整背驰（结构上未确认离开中枢），只代表次级别转折，**不代表走势级别的一买/一卖**；报告背驰判断段会注明此点。
10. **MACD 面积**：每笔区间内 MACD 柱面积，向上笔累加柱>0、向下笔累加柱<0 的绝对值，作为该段力度。
11. **极值实际位置**：笔端点/中枢区间在图表上标注时，使用极值实际出现的原始 bar 序号（而非合并K线组首根），避免低点/高点日期显示偏移（如合并组内低点实际在组内后一根 bar）。
12. **K线极值贴合**：分型确认用合并K线值，可能让笔终点停在分型值上，而同一笔区间内某些原始 K 线的真实低/高更极端（如 5.42 之后还有 5.40、5.22 之后还有 5.20、5.20 之前还有 5.17），但这些 K 线未形成独立底分型，传统矫正抓不到。`fit_extreme_to_kline` 对**每笔（含最后一笔）扫描其完整 K 线区间**，向更极端贴合，并级联更新下一笔起点，使低点/高点贴合肉眼所见 K 线极值；约束：不侵入下一笔（极值不越过下一笔终点组）、极值组距笔起点 ≥ MIN_GAP。仅当存在更极端 K 线时触发，不影响已完成正确划分的笔。

> 如需调整成笔口径（如 MIN_GAP），只改 `chanlon_engine.py` 顶部的 `MIN_GAP` 常量即可。

## 4. 输出报告包含

- **结构摘要**：最近一笔方向/状态、中枢数量、现价在区间的相对位置。
- **中枢定位**：每个中枢的构成笔、上沿 ZG、下沿 ZD、区间宽度。
- **买卖点判断**：一买/二买/三买/三卖，标注"已确认(历史)"或"关注中"。
- **背驰判断**：顶背驰(卖)/底背驰(买)信号，含 MACD 面积对比、**级别标注（笔级别/走势级别）**与力度衰竭说明；并注明"笔级别背驰不代表走势级别买卖点"。
- **图表**：K线 + 笔连接 + 中枢区间(ZG/ZD 标注) + 背驰点标记 + **MACD 柱子面板**（下方面板，正柱绿/负柱红，与 K 线共用缩放）。
- **操作建议**：基于现价相对最近中枢位置给出倾向，附风险提示。
